# MeshUp Website

A responsive, single-file marketing website for the MeshUp app.

## Open locally
Double-click `meshup-website.html` or open it in any modern browser. No build step is required.

## Publish
Upload the HTML file to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any static web host. Rename it to `index.html` if the host requires that filename.

## Notes
- The app preview images are embedded directly in the file.
- The primary buttons link to https://meshup.base44.app/.
- The signup form is a front-end demo and does not store or send data. Connect it to Base44, Microsoft Forms, Mailchimp, HubSpot, or another backend before production.
- Reliability and verification language is presented as product direction where implementation is not confirmed.
